# itshaker-template-base

> Generic template for any new lowcodai project.

[![Governance](https://img.shields.io/badge/governance-lowcodai-blue)](https://github.com/lowcodai/itshaker-copilot-governance)

## Description

This repository is a GitHub template for any new lowcodai project. It includes:
- Standard documentation structure (`docs/adr/`, `docs/architecture/`, `docs/operations/`, `docs/runbooks/`)
- GitHub Copilot configuration (instructions, agents, hooks)
- Issue and pull request templates

`CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, and `.github/workflows/` are intentionally not
shipped in this raw template repo — they are generated by
`itshaker-bootstrap/scripts/apply-template.sh` when a new project is bootstrapped from this
template.

## Usage

### Via the bootstrap (recommended)

```bash
git clone https://github.com/lowcodai/itshaker-bootstrap
cd itshaker-bootstrap
./scripts/new-project.sh --type base --name <my-project>
```

### Via GitHub (template repo)

Click **Use this template** in the GitHub interface.

## Structure

```
.
├── docs/
│   ├── adr/           # Architecture Decision Records (see docs/adr/README.md for the process)
│   ├── architecture/  # Architecture diagrams and documentation
│   ├── operations/    # Operational continuity state for Hermes sessions (CURRENT/HANDOFF/ACTIVITY)
│   └── runbooks/      # Operational runbooks
└── .github/
    ├── copilot-instructions.md  # GitHub Copilot instructions
    ├── instructions/            # Specialized instructions
    ├── agents/                  # Copilot agents (e.g. adr-generator)
    ├── hooks/                   # Copilot hooks
    ├── ISSUE_TEMPLATE/          # Issue templates
    └── PULL_REQUEST_TEMPLATE.md
```

## Governance

This template is managed by [itshaker-copilot-governance](https://github.com/lowcodai/itshaker-copilot-governance).

To sync governance updates:

```bash
./scripts/sync-governance.sh --dest .
```

## Awesome Copilot elements included

| Element | Type | Usage |
|---------|------|-------|
| `adr-generator` | Agent | Generates ADRs |
| `acquire-codebase-knowledge` | Skill | Analyzes the codebase |
| `breakdown-*` | Skills | Task breakdown |
| `audit-integrity` | Skill | Integrity audit |
| `arch` | Plugin | Architecture diagrams |

See `.github/copilot-instructions.md` and the [governance hooks registry](https://github.com/lowcodai/itshaker-copilot-governance/blob/main/docs/awesome-copilot-map.md) for the full list of hooks in use.
